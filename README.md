# Next.js First Steps

Next.js App Router practice app with home, about, contact and pricing pages.

Use Node.js 20.9+ and the committed npm lockfile:

```sh
npm ci
npm run dev
```

Open `http://localhost:3000`. Pages live in `app`; shared navigation lives in `components`.

Run `npm run lint` and `npm run build` to check changes; `npm start` serves a completed production build. No test script is configured. Builds use `next/font/google` and need access to Google Fonts.
